# BillingAFK

Reward users with credits for AFKing. This FeatherPanel addon integrates with **Billing Core** to credit users for time spent on the AFK earnings page.


## Features

- **User-facing**
  - **Earn Credits → AFK Earnings** (`/earn/afk`)
  - Start/stop AFK sessions; periodic work endpoint awards credits
  - Claim rewards manually or auto-claim (admin-configurable)
  - View session status, stats, and current credit balance
  - Optional captcha support (uses panel captcha provider)

- **Admin**
  - **Fremium Earn Credits → AFK Rewards**
  - Enable/disable AFK rewards
  - Credits per minute, reward interval, claim vs auto-claim
  - Session/daily limits (max credits, sessions, time per day)
  - Require active browser tab; optional captcha
  - Custom JavaScript injection on AFK page
  - View all user AFK statistics; per-user stats
